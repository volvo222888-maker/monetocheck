# МонетоЧек

Сайт: вставляешь ссылку на канал (или видео) → видно, показывается ли реклама, и оценку дохода.

## Запуск
1. Получите ключ **YouTube Data API v3**: Google Cloud Console → новый проект → APIs & Services → Library → YouTube Data API v3 → Enable → Credentials → API key.
2. Скопируйте `.env.example` в `.env` и вставьте ключ в `YT_API_KEY`.
3. Нужен Node.js 18+. Запуск: `npm start` → http://localhost:3000

Зависимостей нет.

## Как это работает
- Данные канала и последних 15 видео — через официальный YouTube Data API (~3 единицы квоты на проверку, +100 если ссылка вида /c/имя; лимит 10 000/день).
- Монетизация: сервер открывает страницы 6 последних видео и ищет признаки рекламы в данных плеера. Это **эвристика**: реклама может показываться и без монетизации (и наоборот), а YouTube может менять разметку или показывать капчу/согласие с cookie.
- Доход: просмотры последних видео × средний RPM по категории (Shorts — отдельная низкая ставка). Это оценка, не факт.

## Деплой
Подойдёт любой хостинг Node.js (Render, Railway, Fly.io, VPS). Команда запуска: `npm start`, переменная окружения `YT_API_KEY`.
Результаты кэшируются на час, лимит — 30 проверок в час с одного IP.
