# МонетоЧек v2

Вставляешь ссылку на канал или видео — получаешь статус монетизации, оценку дохода и аналитику.

## Возможности
**Канал:** статус монетизации (по рекламе на последних видео), баннер и аватар, дата создания и возраст, подписчики/просмотры/видео, ID канала, язык, подключение Google Analytics, темы, теги и ключевые слова (копирование), описание, среднее и медиана просмотров, публикаций в неделю, вовлечённость, доля Shorts, график просмотров, оценка дохода (месяц/год/всё время), калькулятор со своим RPM, таблица дохода по категориям, список последних видео с превью.
**Вердикт о монетизации:** крупный блок «Канал монетизирован / частично / не обнаружена / вероятно / не удалось определить» с чек-листом признаков (реклама, 1000+ подписчиков, активность, не «для детей»).
**Диаграмма дохода по времени:** по годам и за 24 месяца, режимы «Доход / Просмотры» и «Накопительно», подсказка по клику или наведению. Учитываются до 500 последних видео.
**Видео:** реклама и примерные рекламные паузы на шкале, просмотры/лайки/комментарии, категория, язык, возрастное и детское ограничения, региональные ограничения, встраивание, теги, темы, описание, оценка дохода и калькулятор RPM, превью в полном размере.
**Ещё:** сравнение двух каналов, история проверок, тёмная тема, кнопки «Поделиться» и ссылка вида `/?q=...`.

## Запуск
1. Ключ **YouTube Data API v3**: Google Cloud Console → APIs & Services → Credentials → Create credentials → API key (Public data).
2. Скопируйте `.env.example` в `.env`, вставьте ключ в `YT_API_KEY`.
3. Node.js 18+: `npm start` → http://localhost:3000. Зависимостей нет.

## Как это работает
- Данные канала и 20 последних видео — через официальный YouTube Data API (около 3 единиц квоты на проверку, +100 для ссылок вида /c/имя; лимит 10 000/день).
- Монетизация — эвристика: сервер открывает страницы 6 последних видео и ищет признаки рекламы. Реклама бывает без монетизации и наоборот, а YouTube может показать окно согласия.
- Диаграмма: YouTube API не отдаёт историю просмотров по дням, поэтому просмотры видео отнесены к месяцу публикации, а доход — просмотры × RPM категории (диапазон от–до). Это оценка.
- Рекламные паузы в видео определяются по данным страницы и могут быть неполными.
- Доход — просмотры × средний RPM категории (Shorts — отдельная низкая ставка). Это оценка, не факт.

## Деплой
Любой хостинг Node.js (Render, Railway, VPS). Команда запуска: `npm start`, переменная окружения `YT_API_KEY`. Кэш результатов — час, лимит — 60 проверок в час с одного IP.
